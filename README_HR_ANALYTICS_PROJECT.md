# HR Analytics Dashboard | Power BI

An interactive HR analytics dashboard built in Microsoft Power BI to explore employee attrition and workforce patterns. The report summarizes key HR metrics and helps users investigate how attrition varies across employee groups.

> **Dashboard screenshots:** Not added yet. I plan to upload screenshots to this repository later.

## Project Overview

Employee attrition is an important workforce metric because turnover can affect recruitment, training, team stability, and business costs. This project uses HR data to summarize workforce metrics and explore attrition patterns across different employee characteristics.

## Project Objectives

- Track overall employee count and attrition rate.
- Explore attrition patterns across employee groups.
- Review workforce characteristics such as department, job role, monthly income, satisfaction, and tenure where available in the dataset.
- Build an interactive report with Power BI visuals and filters.
- Present HR data in a clear, business-friendly format.

## Tools & Skills

- **Power BI Desktop** — dashboard development and visualization
- **Power Query** — data cleaning and transformation
- **DAX** — measures and calculations
- **Data Analysis** — KPI analysis and segmentation
- **GitHub** — project hosting and documentation

## Business Questions

- How many employees are represented in the dataset?
- How many employees have left, and what is the overall attrition rate?
- How does attrition vary across departments and job roles?
- What patterns appear across employee income, satisfaction, age, or tenure?
- Which employee groups may warrant further investigation by HR?

The analysis is exploratory. Patterns in the dashboard do not, by themselves, prove that a particular factor causes attrition.

## How to Open the Dashboard

1. Open the project repository on GitHub.
2. Download `HR_Analytics_Dashboard (2).pbix`.
3. Open the file using **Microsoft Power BI Desktop**.
4. Navigate through the report pages and interact with the available visuals and filters.

## Potential Business Value

The dashboard can help HR teams identify attrition patterns, compare employee groups, and decide where further investigation may be useful. Any retention initiative should be evaluated using additional business context and employee feedback.
